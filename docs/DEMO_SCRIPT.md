# 5 分钟演示视频脚本

目标时长：4 分 30 秒左右，成片不得超过 5 分钟。录屏与机位画面要同时让评审看清触摸交互、AI 识别、称重变化和标签输出。

| 时间 | 画面 | 解说重点 |
|---|---|---|
| 0:00–0:25 | 整机与双板全景，快速扫过摄像头、秤、屏幕、打印机 | 项目解决什么问题；openvela 与飞腾节点如何分工 |
| 0:25–0:55 | openvela 启动后的首页和三页流程 | 320×480 LVGL UI、中文显示、触摸操作与状态反馈 |
| 0:55–1:35 | 点击收件字段并说出姓名、电话、地址 | 小智 STT 把语音结果回填到指定字段，展示修改或清除操作 |
| 1:35–2:20 | 把物品放到秤上，镜头同时拍摄物品和屏幕 | RS485 称重、连续稳定样本、重量稳定后才允许进入下一步 |
| 2:20–3:05 | 摄像头对准物品并触发识别 | 本地 Ollama `minicpm-v4.6:latest` 视觉识别；强调图像不上传云端 |
| 3:05–3:45 | openvela 包裹页出现物品、重量、包装，随后确认提交 | UART 单行 JSON 双向通信和字段完整性 |
| 3:45–4:15 | 打印机输出标签，近景展示脱敏手机号 | 订单去重、手机号脱敏、成功后需移走物品并回零 |
| 4:15–4:30 | 快速展示一次异常保护或 dry-run | 信息不完整、重量不稳或识别失败时不打印，可恢复重试 |

## 拍摄前检查

- 清理屏幕和桌面，固定手机横屏，避免逆光；
- 使用虚构姓名、电话和地址，避免真实隐私；
- 确认 Ollama 模型已在本地、四个串口/视频设备路径正确；
- 先用 `--dry-run` 完整跑一遍，再进行正式打印；
- 视频中至少出现一次完整的触摸操作和一次语音回填；
- 结尾停留 2–3 秒展示整机、屏幕结果和打印标签。
